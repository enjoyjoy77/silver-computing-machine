  ダウンロード整理   つかいかた
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ダウンロードフォルダに たまった画像を、
ボタンひとつで OneDrive の「写真倉庫」へ まとめて移します。
そのとき、画像の日付ごとのフォルダを 自動で作って 仕分けます。

    写真倉庫
      ├ 2026-08-23
      │    b.png
      │    新しい絵.webp
      └ 2026-08-26
           a.jpg


■ ふだんの使い方（3ステップ）

  1. 「1_おためし.bat」を ダブルクリック
       → 何枚あるか、どんな名前かを 見せるだけ。まだ動かしません。

  2. よければ 「2_まとめて移動.bat」を ダブルクリック
       → 写真倉庫へ 移動します（コピーではなく引っ越しです）。

  3. 窓に「○枚を写真倉庫へ移しました」と出れば成功です。
     何かキーを押すと窓が閉じます。


■ ほうっておいても動くようにする（自動）

  「3_自動でやる_オンオフ切替.bat」を ダブルクリックすると、
  オン ⇔ オフ が 入れ替わります。

    オン … 5分おきに Windows が勝手に動かします。画面は出ません。
           ダウンロードした画像が、放っておくと 写真倉庫に片づきます。
           パソコンを再起動しても、そのまま続きます。
    オフ … 自動をやめます。「2_まとめて移動.bat」を押したときだけ動きます。

  いまオンかオフかは、この3番を押したとき（と、1番・2番の窓の上のほう）に出ます。

  自動が動いた記録は「自動のきろく.txt」に1行ずつ残ります
  （「2026-08-26 10:05  3枚を移しました」のような1行）。
  画面が出ないぶん、ちゃんと働いているかは ここで確かめてください。

  間隔を変えたいときは、設定.json の "自動で動かす間隔（分）" を直してから、
  3番を2回押して（オフ→オン）登録し直してください。

  ※ 仕組み: Windows の「タスクスケジューラ」に ClaudeDownloadSeiri という
     名前の仕事を登録／削除しています。常駐（黒い窓）ではありません。


■ 移す先を変えたい・種類を変えたい

  「設定.json」をメモ帳で開くと直せます。

    "有効"            … false にすると 自動も手動も 全部止まります（一時停止）
    "ダウンロード先"  … 空っぽなら Windows のダウンロードフォルダ
    "移動先"          … 空っぽなら OneDrive\写真倉庫
    "対象の拡張子"    … 移す画像の種類
    "日付フォルダを作る" … false にすると 仕分けず 写真倉庫の直下に入れます
    "日付の決め方"    … "ファイルの日付"（画像がPCに来た日。ふつうはこちら）
                        "実行した日"（ボタンを押した日でまとめる）
    "書きかけとみなす秒数" … 直前に落ちてきた分をよける秒数
    "自動で動かす間隔（分）" … 自動のとき 何分おきに動くか

  ※ 場所を書くときは ￥マークを2つ重ねます。
     例: "C:\Users\sirak\OneDrive\写真倉庫"


■ こうなっています（安全のはなし）

  ・ダウンロードの途中らしい画像（15秒以内に更新されたもの）は移しません。
  ・移す先に同じ名前があっても 上書きしません。「名前_2.jpg」にして残します。
  ・画像の中身は開きません。名前と日付だけを見ています。
  ・写真倉庫フォルダと 日付フォルダは、必要になったときに 自動で作ります。


■ うまくいかないとき

  ・「Python not found」と出た → Python が入っていません。
  ・「移せなかったものがあります」と出た →
      その画像を 他のソフト（ビューアなど）で開いたままです。閉じて もう一度。
