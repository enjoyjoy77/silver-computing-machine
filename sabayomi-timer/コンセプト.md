# サバよみタイマー コンセプト（名前は仮）

あなたの「5分で終わる」は、だいたい12分だ。

普通のタイマーは言われた時間を測るだけで、「10分」と入れれば10分で鳴る。でも自分で決めた「10分」は、たいてい10分で終わらない。皿洗いも支度もメールの返信も、人は毎回同じように読み違える。遅刻も締切破りも、根っこはこれ。

このタイマーは読み違えを覚えて、次から勝手に直す。

## 流れ

1. 何をやるか選ぶ。2回目からは履歴のボタンを押すだけ
2. 自分の感覚で「何分」と入れる
3. 「あなたの10分 → たぶん17分」と出て、タイマーは17分で動く
4. 自分で言った10分を過ぎても止まらない。目盛りの色が変わるだけ。17分も越えたら「+2:10」と数え続ける
5. 終わったら「終わった」を押す。見積もりと実際の時間が1件ずつ記録に残る

補正のしかた：同じ「やること」の記録が3件以上あれば、そのやることの「実際 ÷ 見積もり」の中央値をかける。足りなければ全体の中央値。それもなければ仮に1.3倍。

## 普通のタイマーと違うところ

普通のタイマーはゼロになったら仕事が終わる。こっちは見積もりを過ぎてからが本番。過ぎたあとに数えた分が、そのまま次回の補正になる。

見積もりと実際を比べるアプリなら、もうある。でもどれも、ずれを後からグラフで見せるだけ。「平均35%オーバー」と言われても、次に10分と入れるころには忘れている。このタイマーは反省させない。入れたその場で、直した数字を出す。

## 画面

円に針が2本。薄い針が自分の見積もりで、濃い針がほんとの見込み。2本のあいだが、そのまま自分のサバ読みの幅になる。スクショ1枚で何のアプリか分かる。

## 誰が3000円払うか

遅刻と締切破りを繰り返して、自分を責めるのに疲れた大人。ADHD傾向で「時間の感覚がない」と言われてきた人。見積もりが甘くて赤字の仕事を抱えるフリーランス。

タクシー1回、延滞料1回、値付けを間違えた仕事1件で、3000円はすぐ消える。その原因を毎日少しずつ削る道具だ。

使うほど自分の記録がたまって、補正が正確になる。無料のタイマーに乗り換えたら、その記録はゼロからやり直し。3000円の根拠はここにある。

買い切りで、アカウントなし。記録はスマホの外に出ない。

## 弱いところ

最初の数回は補正がほとんど効かない。初回にあるのは、見積もりを越えて「+6分」と伸びていく数字を自分の目で見る体験だけ。それで刺さらない人には売れない。

「終わった」を押し忘れると記録が狂う。見積もりの3倍を越えたら、次に開いたとき「いつ終わった？」と聞いて、ざっくり直せるようにする。

ブラウザ製なので、iPhoneで画面を消すとタイマーは鳴らない。画面をつけっぱなしで置いて使うのが前提になる。記録しているのは始めた時刻と終わった時刻だけだから、鳴らなくても記録は狂わない。

## 最初に作る範囲

1. 開始画面：やることを選ぶ、自分の見積もりを入れる、補正後の時間を見る
2. 進行画面：2本針。見積もりを越えたらカウントアップ
3. 「終わった」と記録。押し忘れたときの救済
4. 相場表：やることごとのほんとの所要時間と、自分の読み違えの倍率

後回しにするもの：出発時刻からの逆算（「8:30に家を出る」と入れると、支度の相場を足して「7:41に動き出せ」と出す）。売るときの合言葉やライセンスの仕組み（ボードゲームの合言葉版と同じ方式）。
