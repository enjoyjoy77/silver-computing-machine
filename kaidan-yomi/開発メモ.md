# かいだん読み 開発メモ

文章を貼ると、単語ごとのアクセント（高低）を辞書から引いて、山の頂点が文末に向かって一段ずつ下がる
「上から下」の読みのお手本を図と音で出す。元ネタは YouTube「あんじょーメソッド」の
『ナレーションの“上から下”を外郎売で徹底解説』。

肝は「各単語のアクセント（高低差）は崩さない。単語の中で一番高い音だけを、文末へ順番に下げる」。
音を全部だらだら下げる「坂道」ではなく「階段」。

## ファイル

- `kaidan.html` … 画面。ブラウザだけで動く（サーバー処理なし）
- `kaidan-core.js` … 中身。モーラ分割・辞書引き・アクセント句の組み立て・階段の段割り。node でも読める
- `accent.tsv` … アクセント辞書（約12万語、3.7MB）。UniDic から抜き出したもの
- `../libs/kuromoji/` … 形態素解析 kuromoji.js 0.1.2 と IPADIC 辞書（約18MB、gzip 済み）

## アクセント辞書の作り方

UniDic（国立国語研究所）にはアクセント型（aType）と結合型（aConType）が入っている。
pip の `unidic-lite`（UniDic 2.1.2）は lex.csv を含まないので、`sys.dic`（MeCab バイナリ）を直接読んで
全 756,264 エントリを吐き出し、IPADIC（kuromoji.js が使う辞書）に表層が存在する語だけ残した。

1. `pip download unidic-lite` → tar 展開 → `sys.dic`
2. sys.dic のヘッダ（10 個の uint32）→ 32 バイトの charset → ダブル配列 → トークン（16 バイト×N）→ 素性文字列
   トークンの `feature` オフセットで素性（CSV）を取る。`orth`（表層）は素性の中にある
3. kuromoji.js の `token_info_dictionary.target_map` を舐めて IPADIC の全表層・基本形を集める
4. 動詞・形容詞は終止形だけ、助詞・助動詞は結合型のあるものすべて、数詞は IPADIC に無くても残す
5. 行の形: `表層 \t 読み|アクセント型|結合型|品詞;...`（品詞は1文字: n名詞 g固有 u数詞 r代名詞 v動詞 a形容詞 j形状詞 d副詞 p助詞 x助動詞 f接頭辞 s接尾辞 …）

作り直すときは scratchpad の `dump_sysdic.py` と `build_accent.py`（このメモの末尾に写しを置く）。

## 結合型の読み方（実例から確定したもの）

名詞・接尾辞（後ろに来る語が持つ）
- C1 … 後ろの語の核をそのまま保つ（源氏物語 → ゲンジモノガ↓タリ）
- C2 … 後ろの語の1拍目に核（山桜 → ヤマザ↓クラ、携帯電話 → ケータイデ↓ンワ）
- C3 … 前の語の最後の拍に核（横浜市 → ヨコハマ↓シ、二十里 → ニジュ↓ーリ）
- C4 … 全体を平板に（田中さん、読み方、〜的）
- C5 … 前の語の核を保つ（〜する）

助詞・助動詞（`名詞%F1,動詞%F2@0,形容詞%F2@-1` のように前の語の品詞ごと）
- F1 … 前に従う
- F2@p … 前が平板なら p に核、起伏ならそのまま（まで: 桜まで → サクラマ↓デ、山まで → ヤマ↓マデ）
- F3@p … 前が起伏なら p に核、平板ならそのまま（ない: 書かない → カカ↓ナイ、感じない → カンジナイ）
- F4@p … いつも p に核（ます → マ↓ス、たい → タ↓イ）
- p は 1 以上なら自分の p 拍目、0 以下なら前の語の末尾から（0=末尾、-1=その前）
- aModType の M1@n は「核を右へ n」（ましょう = F4@1 + M1@1 → マショ↓ー）。使う所は上書き表で直書き

UniDic の値より標準的な読みを優先して上書きしたもの（`OVERRIDE`）
- た・たら・たり（助動詞-タ）は F1。UniDic の F2@1 だと「食べた」が尾高になる
- ましょう F4@2、でしょう/だろう F2@2（形容詞の後は F2@-1）
- 意志の「う」「よう」は F4@0（書こ+う → カコ↓ー）
- 形容詞の後の「ない」は F2@-1（重くない → オモ↓クナイ）

## 活用による核の移動（辞書形の核 k から）

動詞（k>0）
- 終止・連体・未然・仮定・命令・意志: k のまま
- 連用形・音便形: 五段は k のまま、一段・カ変・サ変は k-1（過ぎて → ス↓ギテ、起きて → オ↓キテ）
- 平板（k=0）は全形 0。ただし命令形は後ろから2拍目（開けろ → アケ↓ロ）

形容詞（k>0）
- 基本形・体言接続: k、それ以外の形は k-1（高く → タ↓カク、高かった → タ↓カカッタ）
- 平板（重い）: 連用タ接続・仮定形は語幹末（重かった → オモ↓カッタ、重ければ → オモ↓ケレバ）

核が ー・ン・ッ に乗ったらひとつ前へ。

## 句（ひと山）の組み立て

- 接頭詞（お・ご）は次の語につく。後ろが平板なら平板、起伏なら核をそのまま後ろへ（お方 → オカタ↓）
- 名詞+名詞は複合語（後ろの語の結合型）。代名詞・副詞可能の名詞からはつなげない（拙者 親方 は別の山）
- 名詞+する は C5（愛する のように名詞が2拍以下なら ス に核）
- 動詞連用形+動詞（読み始める）と 連用形+やすい は全体の後ろから2拍目
- て+補助動詞（〜ている・〜てくる）は「先に核がある方が勝つ」（食べていました → タ↓ベテイマシタ、感じていました → カンジテイマ↓シタ）
- 形式名詞（内・こと・もの）は前の山に F1 でつく（お立会いの内に がひと山）
- 辞書に無い複合名詞は 前+後 の2語に分けて引き直す（株式会社 → 株式+会社）
- 「ましょ」+「う」など IPADIC が切りすぎる助動詞は先につなぐ

## 段（階段）

文末（。！？ 改行）で仕切り直し。読点は「自動（4山以上たまっていたら仕切る）」「文末だけ」「読点でも」から選ぶ。
山をタップして「ここから段を上に戻す」で手動の仕切りも置ける。

## 音

Web Audio の三角波＋ローパス。低い拍は一定、高い拍は一番上の山が +12 半音、下の山ほど +3 半音に近づく。
声ではなく「頂点の順番」を耳で確かめる用途。

## わかっている弱点

- 古文・固有名詞は IPADIC の切り方が外れる。外郎売の語はことば帳に最初から入れてある（核が空のものは推定）
- 「の」でつながる名詞句をひと山にするかは話者次第。既定では形式名詞以外は別の山
- 外来語の推定（後ろから3拍目）は外れることがある（スマートフォン）
- 「〜かもしれない」の「しれない」が別の山になる

## 参考: 辞書を作ったスクリプト

```python
# dump_sysdic.py  sys.dic → TSV(全エントリ)
import struct, csv, sys
path, out = sys.argv[1], sys.argv[2]
data = open(path, 'rb').read()
magic, version, dtype, lexsize, lsize, rsize, dsize, tsize, fsize, dummy = struct.unpack_from('<10I', data, 0)
pos = 40 + 32 + dsize            # ヘッダ + charset + ダブル配列
tok_start, feat_start = pos, pos + tsize
feat = data[feat_start:feat_start + fsize]
with open(out, 'w', encoding='utf-8') as w:
    for i in range(tsize // 16):
        lc, rc, posid, wcost, foff, comp = struct.unpack_from('<HHHhIi', data, tok_start + i * 16)
        row = next(csv.reader([feat[foff:feat.index(b'\0', foff)].decode()]))
        w.write(str(wcost) + '\t' + '\t'.join(row) + '\n')
```

```python
# build_accent.py  TSV → accent.tsv  (列: 0 cost, 1 pos1, 2 pos2, 6 cForm, 9 orth, 18 kana, 24 aType, 25 aConType)
import sys, collections
POS = {'名詞':'n','代名詞':'r','動詞':'v','形容詞':'a','形状詞':'j','副詞':'d','助詞':'p','助動詞':'x',
       '接頭辞':'f','接尾辞':'s','感動詞':'k','連体詞':'t','接続詞':'c'}
CAT = {'名詞':'n','動詞':'v','形容詞':'a'}
ipa = set()
for line in open('ipadic_all.tsv', encoding='utf-8'):   # kuromoji の全エントリ(表層 \t ... \t 基本形 ...)
    c = line.rstrip('\n').split('\t'); ipa.add(c[0]); ipa.add(c[7])
best = {}
for line in open('unidic_all.tsv', encoding='utf-8'):
    c = line.rstrip('\n').split('\t')
    cost = int(c[0]); pos1, pos2, cform, orth, kana, atype, acon = c[1], c[2], c[6], c[9], c[18], c[24], c[25]
    if pos1 not in POS or not orth or not kana: continue
    code = POS[pos1]
    if pos1 == '名詞': code = 'g' if pos2 == '固有名詞' else 'u' if pos2 == '数詞' else 'n'
    if pos1 in ('動詞', '形容詞') and not cform.startswith('終止形'): continue
    if pos1 in ('助詞', '助動詞'):
        if acon in ('', '*'): continue
    elif pos1 in ('接頭辞', '接尾辞'):
        if acon in ('', '*') and atype in ('', '*'): continue
    else:
        if atype in ('', '*'): continue
        if orth not in ipa and code != 'u': continue
    if acon == '*': acon = ''
    if '%' in acon:
        parts = []
        for seg in acon.replace('形容詞%', ',形容詞%').replace('動詞%', ',動詞%').replace('名詞%', ',名詞%').split(','):
            seg = seg.strip()
            if not seg: continue
            k, _, v = seg.partition('%')
            if k in CAT: parts.append(CAT[k] + ':' + v)
        acon = ' '.join(parts)
    key = (orth, kana, code)
    if key not in best or cost < best[key][0]: best[key] = (cost, atype, acon)
by = collections.defaultdict(list)
for (orth, kana, code), (cost, atype, acon) in best.items(): by[orth].append((cost, kana, atype, acon, code))
with open(sys.argv[1], 'w', encoding='utf-8') as w:
    w.write('# accent dictionary derived from UniDic (unidic-lite 2.1.2). 表層\t読み|アクセント型|結合型|品詞;...\n')
    for orth in sorted(by):
        seen, out = set(), []
        for cost, kana, atype, acon, code in sorted(by[orth]):
            sig = (kana, atype, acon, code)
            if sig in seen: continue
            seen.add(sig); out.append('|'.join([kana, atype, acon, code]))
        w.write(orth + '\t' + ';'.join(out) + '\n')
```
