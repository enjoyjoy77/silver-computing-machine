モデル・送信と料金

GeminiはサーバーSecretの設定後に使用できます。文字・画像参照・文書の抽出テキスト・画像生成／編集（Gemini Nano Banana 2.1、1K正方形）に対応。Web検索・録音・API読み上げは未対応です。プロバイダー変更は新規会話となり、他社の会話は送信しません。Gemini 3.5 Flash-Liteは軽量、3.8 Flashは高性能の選択肢です。モデルで料金と利用資格が異なります。推論も出力枠を使うため回答が途中で終わる場合があります。モデル名だけ端末に保存します。Google AI Proの契約とAPIの利用枠は別途確認が必要です。

会話モデルは文字・検索・添付・音声後の回答に使用します。画像生成・音声認識・読み上げのモデルは別です。モデル名のみ端末に保存します。料金・利用権限はモデルで異なります。Solは推論にも出力枠を使うため、短い回答や途中終了になる場合があります。

音声と利用上限

OpenAIの録音は最大60秒・2MB。音声はgpt-transcribeで文字にし、選択した会話モデルが回答します。読み上げは端末・ブラウザーの合成音声です。音声によってはブラウザー提供元で処理されます。リアルタイムの割り込み会話ではありません。

1ログインにつき1分6回、サイト全体でUTCの1日100回のAPI送信まで。音声1往復は通常2回です。うち画像生成／編集は1日30回、Web検索は30回まで。参照画像は最大4枚。元画像は各5MiB・合計20MiB・4000万画素以内、順に最大1024pxのPNGへ変換し各2MiB・合計4MiBまで送信します。画像が増えると入力料金も増えます。文書は1ファイルずつです。出力画像は1リクエスト1枚のままです。OpenAIの画像生成はGPT Image 2.5 Flare・1024×1024・下書き品質1枚です。Web検索は最大1回/送信。金額の上限ではありません。停止しても処理済み分には料金が発生する場合があります。

テーマ

この画面は専用の合言葉で保護されています。ログインは通常8時間、ログイン画面で選んだ端末のみ30日間です。画像理解・画像生成／編集・短いテキスト資料・Web検索に対応します。PDF（10ページ以内）・DOCX・XLSX・PPTXは端末内で文字だけを抽出します。2MB・抽出8000文字以内、スライド/シート20個以内。スキャン画像・図表・書式・旧Office形式・マクロ・暗号化文書は未対応です。元ファイルは送信しません。リアルタイム音声・ファイル保管は未対応です。

履歴はこのブラウザーだけに平文で保存します。同じ端末・ブラウザーを使う人や同一サイトのスクリプトから読み取れるため、共有端末では利用後に履歴を削除してください。ログアウトでは消えません。ブラウザーデータを削除すると失われます。自動削除はしません。IndexedDBに保存し、アプリ上限100MiB・100会話・計2000メッセージです。画像は別のバイナリ記録にします。端末の空き容量やブラウザーの制限で、上限前でも保存できない場合があります。移行前の履歴は移行完了後もバックアップとして残り、「すべて削除」で消去します。旧版タブの変更は自動統合せず通知します。元の添付ファイル・録音・読み上げ音声・認証情報は保存しません。生成画像も容量内で保存します。
